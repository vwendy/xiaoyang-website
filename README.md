# Xiao Yang's website

A lightweight, static personal website designed for GitHub Pages. It has no build step and no hosting lock-in.

## Edit the content

- Edit `index.html` for page copy, publications, links, and contact details.
- Edit `styles.css` for the visual design.
- Place new images or PDFs in an `assets/` folder and link to them with relative paths.

## Preview locally

Open `index.html` in a browser. For the closest local preview, use any simple static-server extension or tool.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `xiaoyang-quantpsych.github.io`.
2. Add these files to its main branch.
3. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. GitHub will publish it at `https://<your-github-username>.github.io/` (or at the project path if you choose a project repository).
5. Only after the GitHub Pages site is working, update the DNS records for `www.xiaoyang-quantpsych.com` at your domain registrar. GitHub's custom-domain instructions will show the exact records for the repository.

Keep the Wix site active until the GitHub Pages version and custom domain have both been tested.
